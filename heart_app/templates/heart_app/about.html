Research overview

Existing system and proposed extension

CardioLens compares multiple machine-learning approaches for a binary heart-disease prediction task. It provides a Django interface for dataset preparation, model training, evaluation, and demonstration predictions. Reported metrics should come from the local experiment rather than assumed benchmark values.

▤

Existing system — base paper

Research foundation supplied with this project

Ahmad et al., “Comparative Study of Optimum Medical Diagnosis of Human Heart Disease Using Machine Learning Technique With and Without Sequential Feature Selection,” IEEE Access (2022).

DOI: 10.1109/ACCESS.2022.3153047

The supplied project notes describe a comparison of LDA, Random Forest, Gradient Boosting, Decision Tree, SVM, and KNN. The study uses Sequential Feature Selection (SFS), five-fold cross-validation, and evaluation measures including accuracy, sensitivity, specificity, F1, and ROC-AUC.

Machine learning Sequential feature selection 5-fold CV
Accuracy values reported in the paper belong to its particular dataset variants and evaluation protocol. They should not be copied as results for this implementation.
✦

Proposed extension

Methods implemented in this project pipeline

  • Compare eight model approaches, including Logistic Regression and Random Forest with forward Sequential Feature Selection.
  • Use a stratified 80/20 holdout and stratified five-fold cross-validation on the training portion.
  • Report accuracy, balanced accuracy, precision, sensitivity, specificity, F1, ROC-AUC, and confusion counts where generated by the pipeline.
  • Use preprocessing pipelines and perform feature selection inside cross-validation folds to reduce data leakage.
  • Save the trained model and comparison CSV to support reproducible inference.

Limitations and responsible use: CardioLens is an educational research prototype, not a validated medical device. Small or historical datasets can produce optimistic estimates, especially when duplicate records or data leakage are present. External validation and appropriate clinical governance would be required before any real-world medical use. Do not use its output to make diagnosis or treatment decisions.
